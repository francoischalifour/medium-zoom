# Security policy

## Supported versions

Security fixes target the latest published version of `medium-zoom`. Please upgrade to the latest release before checking whether a vulnerability still applies.

## Report a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/francoischalifour/medium-zoom/security/advisories/new) to report a vulnerability. Please do not report vulnerabilities in public issues or pull requests.

Include the affected version, a description of the vulnerability and its impact, and steps or a minimal example that reproduces it. Include any proposed fix if you have one.

The maintainer will investigate and coordinate a fix and disclosure with you. Please keep the report private until a fix or other mitigation is available.
