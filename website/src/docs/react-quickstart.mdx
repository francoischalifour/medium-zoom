Add the React component and render a zoomable image with `<ImageZoom>`.

## Install the component

In a project configured for shadcn/ui, run:

<InstallCommand page="react" id="react-installation" />

The registry copies the component and stylesheet into your project and installs `medium-zoom`. You can edit those files to match your application.

## Display an image

Import `<ImageZoom>` from your configured components directory. With the usual shadcn/ui alias:

<Example code={photoCode} title="photo.tsx">
  <Photo />
</Example>

<div id="image-props" />
<div id="keyboard-access" />

Replace the image URL with your own. `alt` describes the image and labels the button. Width and height reserve space while the image loads.

<Kbd>Enter</Kbd> or <Kbd>Space</Kbd> on the button opens the image.
Press <Kbd aria-label="Escape">Esc</Kbd>, click the enlarged image or
its background, or scroll to close the zoom.

<div id="zoom-options" />

## Browser support

The React component follows the browser requirements of your React application and its build tooling.
