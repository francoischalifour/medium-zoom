## JavaScript

Set `data-zoom-src` on the image. Its value is the HD image URL:

```html
<img
  src="/photo-preview.jpg"
  data-zoom-src="/photo-large.jpg"
  alt="A mountain at sunrise"
  width="1200"
  height="800"
  data-zoomable
/>
```

Attach the image after adding it to the document:

```js
import mediumZoom from 'medium-zoom'

mediumZoom('[data-zoomable]')
```

Opening the zoom loads `/photo-large.jpg`. Use the same aspect ratio for the preview and HD image.
