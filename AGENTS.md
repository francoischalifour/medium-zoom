# Agent instructions

Read [CONTRIBUTING.md](CONTRIBUTING.md) before changing anything, and follow it. These notes cover only what differs for an agent.

- Config files are the source of truth: browser targets, entries, budgets, ports, and test projects live in the files that CONTRIBUTING.md points to. Read those files instead of relying on a summary, including your own memory of an earlier session.
- Report sizes and runtime costs with the commands in [Measure size and runtime](CONTRIBUTING.md#measure-size-and-runtime), not with measurements of your own.
- When a check cannot run where you are, say so and leave it to CI.
